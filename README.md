# 🌊 COLLECTOPIA Aqua Rescue

### Play • Collect • Protect • Restore

**COLLECTOPIA Aqua Rescue** is a mobile-first 3D endless runner game set in a stylised Indian neighbourhood, featuring a river-inspired environment and environmental awareness elements.

The game combines interactive gameplay, coin collection, mathematical decision-making, obstacles, enemies and power-ups to create an engaging gaming experience while promoting awareness about protecting our water bodies and aquatic environment.

Navigate through different zones, make strategic decisions, collect rewards and overcome challenges as the adventure continues!

---

## 🎮 Game Overview

COLLECTOPIA Aqua Rescue brings together an immersive 3D environment and arcade-style gameplay.

Players control an automatically running character, navigate through three lanes, collect coins, interact with mathematical gates, defeat enemies and avoid obstacles.

The game features progressively challenging levels, interactive environments, dynamic effects and responsive controls designed for both desktop and mobile devices.

## ✨ Key Features

### 🏃 Dynamic Gameplay
- Three-lane endless runner mechanics.
- Smooth lane switching using swipe, drag and keyboard controls.
- Increasing difficulty and speed progression.
- Ten designed levels followed by endless generated levels.

### 🪙 Collectible & Reward System
- Interactive gold coin collection.
- Floating reward animations.
- Lifetime coin tracking.
- Unique reward identification to prevent duplicate collection.

### 🚪 Mathematical Gate System
- Interactive river gates with mathematical operations.
- Seven possible gate values:
  - +100
  - -50
  - -100
  - ×1
  - ×2
  - ÷2
  - ÷4
- Dynamic balance calculations based on the selected gate.

### ⚡ Power-Ups
Five power-ups enhance the gameplay experience:

| Power-Up | Function |
|---|---|
| Magnet | Attracts nearby coins |
| Shield | Protects against one hit |
| Super Punch | Enables powerful attacks |
| Double Coins | Doubles coin rewards |
| Freeze | Temporarily freezes enemies |

### 👾 Enemies & Obstacles
- Interactive enemy encounters.
- Punch-based combat mechanics.
- Breakable walls.
- Collision detection.
- Shield-based protection.

### 🌳 Immersive Environment
- Procedurally generated Indian neighbourhood.
- Seven themed environmental zones.
- Smooth transitions between zones.
- 3D streets, buildings and environmental elements.
- Procedural textures and materials.
- Dynamic particle effects.

### 📱 Mobile-Friendly Experience
- Touch and swipe controls.
- Responsive HUD.
- On-screen punch button.
- Mobile-friendly gameplay interactions.

### 🔊 Audio & Visual Effects
- Coin collection sounds.
- Mathematical gate sound effects.
- Power-up audio feedback.
- Punch and collision sounds.
- Web Audio-based effects.
- Animated gameplay feedback.

## 🚀 Getting Started

Follow these steps to run COLLECTOPIA Aqua Rescue locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Hacker004rahul/collectopia-aqua-rescue.git
```

### 2. Navigate to the Project

```bash
cd collectopia-aqua-rescue
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to play the game.

## 🧪 Build & Testing

Run the production build:

```bash
npm run build
```

Run the test suite:

```bash
npm test
```

Run tests in watch mode:

```bash
npm run test:watch
```

The project uses TypeScript type checking, Vite production builds and Vitest-based automated testing.
